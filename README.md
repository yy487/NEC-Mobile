# NEC Mobile

**简体中文** | [English](README.en.md) | [日本語](README.ja.md)

在 Android 上运行 PC-88 和 PC-98 游戏。项目将 M88 的 PC-88 内核与 NP2kai 的 PC-98 内核集成到同一个应用，分别管理两种平台的游戏、资源和机器配置。

当前版本 **0.26.6**，适用于 **Android 8.0 及以上、ARM64** 设备。

- Android 安装包 `NEC-Mobile-0.26.6-arm64.apk`
- 源码包 `NEC-Mobile-0.26.6-sources.zip`

## 功能

- 按游戏导入文件夹或 ZIP，用卡片管理磁盘、封面和上次游玩时间。
- 双软驱运行中换盘、退盘，支持 PC-88 D88 文件中的多张内嵌盘。
- 相对触控板鼠标、屏幕键盘、实体键盘输入和自动旋转。
- 按游戏保存机型、CPU、内存、声卡及分项音量。
- 每款游戏 6 个手动即时存档槽。
- SF2 MIDI 合成，以及前后台和音频设备切换后的声音恢复。
- Compose / Material 3 平台入口、独立配置页与启动盘位弹层。
- 独立自动会话槽、运行速度、画面比例、手机采样率与缓冲设置。
- PC-98 DOS 目录导入为专用 HDI，支持 FREECG98.BMP 字库。

## 开始使用

1. 安装 APK，打开应用并选择 **PC-88** 或 **PC-98**。
2. 应用会自动准备默认启动固件和字库。游戏如需其他固件，可从 **设置 → 导入系统 ROM / 字库** 导入，也可与磁盘放在同一游戏文件夹或 ZIP 中。
3. 点击 **添加游戏**，选择单款游戏的文件夹或 ZIP，将整套磁盘一起导入。
4. 点击游戏卡片启动。需要调整时，PC-98 使用 **游戏管理 → 启动环境与盘位**，PC-88 使用 **默认盘位**。软驱 A、B 与硬盘可独立装入，选择本次引导设备并保存。

应用使用导入后的磁盘副本保存游戏进度。再次点击卡片时，按已记住的启动盘组合启动机器。

| 平台 | 可导入的磁盘格式 |
| --- | --- |
| PC-88 | D88、88D，单个文件最多 64 张内嵌盘 |
| PC-98 软盘 | D88、88D、FDI、XDF、HDM |
| PC-98 硬盘 | HDI、NHD、HDD、THD，通过启动盘配置加载 |

游戏卡片的 **管理** 提供重命名、机器与音源设置、磁盘导出和移除操作。封面可使用名为 `cover`、`folder`、`front` 或 `title` 的 PNG、JPEG、WebP 图片，也可通过 **菜单 → 更多设置 → 将当前画面设为封面** 截取。

## 操作

运行界面的快捷操作位于半透明工具球中，点击展开或收起，可拖动贴边，横竖屏分别记住位置。展开后提供 Enter、键盘、操作方式与菜单，PC-88 另提供空格。返回键可收起已展开的工具面板。

从 **菜单 → 操作方式 / 鼠标** 选择自动配置、虚拟鼠标或滑动按键。自动配置使用已套用的操作预设，其次沿用上次方式，首次使用滑动按键。完整鼠标通信会触发“试用鼠标”建议，点击后按游戏保存选择。运行界面的按键／鼠标按钮可直接切换，长按打开设置，切换在当前触摸结束后生效。

**操作预设**提供小键盘或方向键配合 Enter／空格、鼠标触控板和文字命令输入。已确认的标题匹配会显示预设建议，确认套用后关联当前游戏副本。

| 操作 | 效果 |
| --- | --- |
| 在虚拟鼠标模式下滑动 | 相对移动游戏光标 |
| 单指轻触 | 在光标当前位置点击左键 |
| 双指轻触 | 点击右键 |
| 长按约 350 毫秒后滑动 | 按住左键拖动 |
| 左下角左右键 | 点击或按住，可配合另一只手滑动 |
| 确认 / 空格 / 键盘 | 发送 Enter、Space 或展开屏幕键盘 |

滑动按键模式下，上下左右滑动各触发一个小键盘 2/4/6/8 按键，也可切换为方向键。单指轻触发送所选的 Enter 或空格，双指轻触发送另一确认键。数字选择等操作可使用屏幕键盘。屏幕方向可从 **菜单 → 屏幕方向** 选择自动、横屏或竖屏。

游戏在切后台或失去音频焦点时暂停，回到前台并取得焦点后，按手动暂停设置决定是否继续。耳机断开后，从菜单选择 **继续运行**。需要手动恢复声音时，使用 **菜单 → 更多设置 → 恢复声音输出**。

## 游戏中途换盘

1. 游戏提示换盘时，打开 **菜单 → 更换 / 取出磁盘**。
2. 按游戏提示选择软驱 A 或 B，再点 **换入其他盘**。
3. 选择游戏要求的盘，返回游戏并按提示继续。

列表显示本游戏已导入的软盘。D88 内含多张盘时，按内部盘名或序号选择。空槽使用 **装入磁盘**，退盘使用 **取出当前盘**。换盘沿用当前运行会话，硬盘镜像通过启动配置选择。

## 存档与进度

从 **菜单 → 即时存档 / 读档** 打开六槽面板，选择一个槽保存、读取或删除。重新启动游戏后，可从这里读取已有即时档。

即时档保存 CPU、内存、设备状态、装盘组合和 MIDI 通道。读取时，恢复的机器状态与磁盘当前内容一起使用。游戏自带的存档功能将进度写入磁盘副本。

读取即时档会恢复其装盘组合。需要更换机器或硬盘环境时，应用重新启动游玩进程并使用保存时的配置。托管系统盘的历史副本继续保留，移除磁盘前会检查即时档引用。

需要保留游戏内存档时，从 **管理 → 管理磁盘文件 → 导出磁盘副本** 导出对应磁盘。移除游戏或卸载应用会删除应用内磁盘和即时档。

在 **游戏管理 → 系统设置** 中启用自动保存后，切后台和正常退出会写入独立会话槽。用卡片的 **继续会话** 恢复，六个手动槽保持独立。恢复失败时会说明原因，可选择正常启动。

## 机器、音源与 MIDI

从游戏卡片的 **游戏管理 → 系统设置** 调整配置，修改在下次启动生效。

- **PC-88** 提供 N88-V1(S)、N88-V1(H)、N88-V2、N、N80、N80-V2 模式、4/8 MHz、扩展内存、OPN/OPNA 和 FM、SSG、ADPCM、节奏音量。
- **PC-98** 提供 VX/VM/PC-286、CPU/FPU 档位、内存，以及 86、26K、118、SB16 等声卡及组合，支持 FM、SSG、ADPCM、PCM、节奏和 BEEP 音量。

PC-88 增加主副 CPU 比例、副 CPU 调度、CPU / 软驱等待、DIP-SW、PCG 和显示时序。PC-98 增加声卡 BIOS、GDC、扫描线、调色板和 LCD 设置。

模拟运行速度提供 50%、100%、150%、200%，音高随速度变化；全速模式静音。画面支持 4:3、原始比例、填满与整数缩放，方向按游戏保存。整数缩放在屏幕放不下原始尺寸时按比例缩小。

从平台的 **设置 → 手机音频输出** 选择应用共用的采样率与缓冲，下次启动生效。播放器的 **更多设置 → 实际音频输出** 显示当前路由及 AAudio 实际参数；内核 PCM 与输出采样率不同时自动重采样。

从 **游戏管理 → 字库设置 · FREECG98.BMP** 选择或导入 PC-98 字库。导入后立即选用，下次启动生效。优先级为手选、游戏包、全局导入、内置；同一来源优先使用 FREECG98.BMP、FONT.BMP，再使用 FONT.ROM。2048×2048、1 位未压缩 BMP 会生成内核使用的副本，原文件保留。系统设置的上次启动信息显示实际加载格式。

若文件夹内的日文磁盘名称在解压时被按 GBK 错译，可用 **游戏管理 → 修复磁盘名称编码** 预览恢复结果并应用。操作只修改显示名称，无需重新导入磁盘。

### MIDI

1. 从首页 **设置 → MIDI 音色库** 导入并选择 SF2，每份最大 64 MB。
2. 在该游戏的 **音源设置** 中启用 MIDI。
3. 启动游戏，在游戏自身的设置中选择 MIDI 音乐。

MIDI 通过 TinySoundFont 使用 SF2 合成 General MIDI 音乐。PC-98 使用 MPU-98，默认端口 E0D0/E0D2、IRQ 6。PC-88 使用 C2/C3 串行接口。游戏镜像和 SF2 音色库由使用者自行准备。

## PC-98 DOS 游戏目录

1. 在 PC-98 库选择 **添加游戏 → DOS 游戏目录 / DOS 游戏 ZIP**，导入完整目录。
2. 默认使用内置 FreeDOS(98) 模板，确认 BAT / EXE / COM 启动文件。
3. 点击 **建立硬盘**。工作目录、盘符、初始化命令与其他 DOS 模板可在高级启动设置中调整。

每款游戏使用独立的可写 HDI。文件名需符合代码页 932 的 DOS 8.3 规则，不兼容名称、重名与空间不足会中止导入。自备模板支持 PC-98 FAT12 / FAT16 分区，系统文件可为 IO.SYS、MSDOS.SYS、COMMAND.COM，或 FreeDOS 的 KERNEL.SYS、COMMAND.COM。可从磁盘管理导出游戏 HDI，备份游戏内存档。

应用会为每款游戏创建可写的系统副本。需要特定版本的商用 DOS 时，可导入自备的 PC-98 HDI 模板。

### 启动环境与存档盘

PC-98 导入磁盘时读取引导信息与 DOS 文件。明确缺少 DOS 且入口清晰时，自动生成系统盘并安排盘位。已有自启动环境的游戏沿用游戏配套环境。

从 **游戏管理 → 启动环境与盘位** 选择自动准备或 FreeDOS(98)。存在多个入口时，选择游戏数据盘，填写盘内启动文件路径并点击 **准备启动环境**。加入自备 MS-DOS 资源的本地构建还可使用 MS-DOS 2.1、3.3D、5.0A、6.2，以及 DOS 6.2 的 HIMEM／EMM386。

从 **管理磁盘文件 → 添加内置磁盘** 创建 1.2 MB FAT12 存档盘或 DOS 维护工具盘。运行中也可从换盘面板新建存档盘，选择装入软驱 A 或 B。新盘保存在该游戏的磁盘列表，可再次装入与导出。FreeDOS 工具盘可从软驱 A 启动，提供 DIR、COPY、TYPE 和 SYS 等命令。

## 运行资源

模拟核心与运行库随 APK 提供，手机只需 Android 8.0 及以上的 ARM64 系统。

| 资源 | 当前提供方式 |
| --- | --- |
| 游戏磁盘、完整 DOS 游戏目录及配套驱动 | 玩家提供；目录中的启动脚本与驻留程序需随游戏完整导入 |
| PC-88 常用 BASIC、软驱、字符与汉字 ROM | 已内置，覆盖六种 BASIC 模式 |
| PC-98 兼容 BIOS、标准字库、默认声卡 BIOS | 内核与 APK 已提供；普通默认配置无需另找 |
| DOS 启动系统 | 默认内置 FreeDOS(98)，也可导入其他 PC-98 HDI 模板 |
| SF2 MIDI 音色库 | 当前需自行导入，仅启用 MIDI 时需要 |
| 汉化或特殊字体映射所需字库 | 使用游戏配套字库；标准字体已内置 |
| 其他声卡 ROM、PC-88 辞书或扩展 ROM | 按软件和特殊硬件配置提供，常规启动不要求 |
| OPNA 节奏采样 `2608_*.WAV` | 已内置六个采样，并支持导入后的小写名称及 RYM / RIM 别名 |

## 构建

Windows 构建需要 **Python 3.11+、Node.js 22+、JDK 17+、CMake 3.22+**。在项目根目录运行以下命令，将占位符替换为本机路径。

```powershell
node scripts/download.mjs
python -X utf8 scripts/extract.py
python -X utf8 scripts/build.py --jdk '<JDK_PATH>' --cmake '<CMAKE_EXE>'
```

构建使用 Gradle Wrapper 9.1.0、AGP 9.0.0、Kotlin / Compose 编译插件 2.2.10、API 36 Extension 19、NDK r28c。脚本将 SDK / NDK 放到 `.cache/`，通过 Gradle 编译 Kotlin 界面和四个原生库，产物写入 `release/`。版本统一在 `version.properties` 中维护。

覆盖更新需恢复原来的 `.cache/signing/development.jks`。全新项目可用自己的 RSA 密钥创建这个文件，alias 为 `necmobile`、开发密码为 `android`。私钥不随源码包分发。

默认构建包含 FreeDOS(98)。在本地加入自备 MS-DOS 资源时，使用 `scripts/build.py --bundle-dos --dos-assets <资源目录>`。资源目录下的 `dos/` 可提供 `default.hdi.gz`、`boot/dos{21,33,50,62}-v1.fdi.gz`、`tools/dos62-v1.fdi.gz` 和 `drivers/` 下的 HIMEM.SYS、EMM386.EXE、MEM.EXE 对应的 .gz 文件。

### 源码打包

```powershell
python -X utf8 scripts/package_sources.py
```

## 代码结构

游戏库和设置使用 Kotlin、Compose / Material 3，业务与播放器使用 Java 17；模拟宿主使用 C/C++、JNI、ANativeWindow 和 AAudio，DOS 文件系统写入使用 FatFs。

| 目录 | 内容 |
| --- | --- |
| `app/` | 游戏库、运行界面、输入与设置 |
| `native/` | 模拟线程、视频、音频、MIDI 与内核适配 |
| `third_party/` | M88、NP2kai、TinySoundFont、FatFs 源码 |
| `scripts/` | 依赖下载、源码适配、构建与打包 |
| `tests/` | Java、原生代码与 Android 功能检查 |
| `release/` | APK 和源码包 |
