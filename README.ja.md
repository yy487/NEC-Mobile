# NEC Mobile

[简体中文](README.md) | [English](README.en.md) | **日本語**

PC-88 と PC-98 のゲームを Android で遊ぶためのエミュレーターです。M88 の PC-88 コアと NP2kai の PC-98 コアを一つのアプリに組み込み、ゲームライブラリ、リソース、マシン設定をプラットフォームごとに管理します。

現在のバージョンは **0.2.4-alpha**。**Android 8.0 以降の ARM64 端末**に対応しています。

- [APK をダウンロード](https://github.com/yy487/NEC-Mobile/releases/download/v0.2.4-alpha/NEC-Mobile-0.2.4-alpha-arm64.apk)
- [ソースコード一式をダウンロード](https://github.com/yy487/NEC-Mobile/releases/download/v0.2.4-alpha/NEC-Mobile-0.2.4-alpha-sources.zip)

## 主な機能

- フォルダーや ZIP からゲームを取り込み、ディスク、カバー画像、最終プレイ日時をゲームカードで管理。
- プレイ中のフロッピーディスク交換と取り出し。PC-88 の D88 ファイルに格納された複数ディスクにも対応。
- 相対移動式のタッチパッドマウス、画面キーボード、物理キーボード入力、画面の自動回転。
- 機種、CPU、メモリー、サウンドボード、各音源の音量をゲームごとに保存。
- 各ゲームに 6 個の手動ステートセーブスロット。
- SF2 を使った MIDI 合成と、バックグラウンド移行や音声出力先の変更に伴う音声復帰処理。

## はじめに

以下のメニュー名は、アプリの中国語表記に合わせています。

1. APK をインストールしてアプリを開き、**PC-88** または **PC-98** を選びます。
2. ゲームに必要なシステム ROM とフォントを用意し、**设置 → 导入系统 ROM / 字库** から取り込みます。ゲーム専用のリソースは、ディスクと同じフォルダーや ZIP に入れて取り込むこともできます。
3. **添加游戏** を押し、一つのゲームとそのディスク一式が入ったフォルダーまたは ZIP を選びます。
4. ゲームカードをタップして起動します。起動ディスクを変更する場合は、**管理 → 启动磁盘** で 1 枚目と 2 枚目を選びます。

ゲームの進行状況は、取り込んだディスクのコピーに保存されます。次回カードをタップすると、記憶したディスク構成でマシンが起動します。

| プラットフォーム | 取り込めるディスク形式 |
| --- | --- |
| PC-88 | D88、88D。1 ファイルにつき最大 64 枚のディスクを格納可能 |
| PC-98 フロッピー | D88、88D、FDI、XDF、HDM |
| PC-98 ハードディスク | HDI、NHD、HDD、THD。起動ディスク設定から読み込み |

ゲームカードの **管理** から、名前の変更、マシン・音源設定、ディスクの書き出し、削除を行えます。カバー画像には、ファイル名が `cover`、`folder`、`front`、`title` の PNG、JPEG、WebP を使えます。プレイ中の画面を **菜单 → 更多设置 → 将当前画面设为封面** からカバーにすることもできます。

## 操作方法

**菜单 → 操作方式 / 鼠标** で入力モードを選びます。初期設定は PC-88 がキー操作、PC-98 が仮想マウスです。選択はゲームごとに保存されます。

| 操作 | 動作 |
| --- | --- |
| 仮想マウスモードでスライド | ゲームのカーソルを相対移動 |
| 1 本指でタップ | カーソルの現在位置で左クリック |
| 2 本指でタップ | 右クリック |
| 約 350 ミリ秒長押ししてからスライド | 左ボタンを押したままドラッグ |
| 左下のマウスボタン | クリック、または押したまま別の指でスライド |
| 确认 / 空格 / 键盘 | Enter、Space の送信、または画面キーボードの表示 |

キー操作モードでは、ゲーム画面のタップで Enter を送信します。数字の選択肢やキー入力が必要な場面では画面キーボードを使います。画面の向きは **菜单 → 屏幕方向** で自動、横向き、縦向きから選べます。

バックグラウンドへの移行やオーディオフォーカスの喪失でゲームを一時停止します。前面に戻ってフォーカスを取得すると、手動の一時停止設定に従って再開します。イヤホンが切断された場合は、メニューから **继续运行** を選びます。音声出力を手動で再開するには、**菜单 → 更多设置 → 恢复声音输出** を使います。

## プレイ中のディスク交換

1. ゲームからディスク交換を求められたら、**菜单 → 更换 / 取出磁盘** を開きます。
2. 操作するドライブを選び、**换入其他盘** を押します。
3. 指定されたディスクを選び、ゲームに戻って指示に従います。

一覧には、そのゲームに取り込んだフロッピーが表示されます。複数枚を格納した D88 は、内部ディスク名や番号で選びます。空のドライブには **装入磁盘**、取り出しには **取出当前盘** を使います。ディスク交換は実行中のセッションに反映されます。ハードディスクイメージは起動設定から選びます。

## セーブと進行状況

**菜单 → 即时存档 / 读档** で 6 スロットのパネルを開き、保存、読み込み、削除を選びます。ゲームを起動し直した後も、保存済みのステートを読み込めます。

ステートには CPU、メモリー、デバイス状態、挿入ディスクの構成、MIDI チャンネルが保存されます。読み込み時には、復元したマシン状態とディスクの現在の内容を組み合わせて実行します。ゲーム内のセーブ機能は、進行状況をディスクのコピーに書き込みます。

ステートを読み込む際は、保存時と同じゲームのコピー、マシン構成、音源ハードウェア設定を使います。MIDI の有効・無効も合わせます。ミキサーの音量と SF2 音色ライブラリは変更できます。

ゲーム内セーブを保管するには、**管理 → 管理磁盘文件 → 导出磁盘副本** から該当ディスクを書き出します。ゲームの削除やアプリのアンインストールで、アプリ内のディスクとステートも削除されます。

## マシン・音源・MIDI 設定

ゲームカードの **管理 → 机器设置 / 音源设置** から設定を変更します。変更は次回起動時に反映されます。

- **PC-88** は N88 BASIC モード、4/8 MHz、拡張メモリー、OPN/OPNA、FM・SSG・ADPCM・リズム音量を設定できます。
- **PC-98** は VX/VM/PC-286、CPU/FPU プロファイル、メモリー、86・26K・118・SB16 などのサウンドボードとその組み合わせを選べます。音量調整は FM、SSG、ADPCM、PCM、リズム、BEEP に対応します。

### MIDI

1. ホーム画面の **设置 → MIDI 音色库** から SF2 を取り込み、使用する音色ライブラリを選びます。1 ファイルの上限は 64 MB です。
2. そのゲームの **音源设置** で MIDI を有効にします。
3. ゲームを起動し、ゲーム側の設定でも MIDI 音楽を選びます。

TinySoundFont が選択した SF2 を使い、General MIDI の音楽を合成します。PC-98 は標準で MPU-98 の E0D0/E0D2 ポート、IRQ 6 を使います。PC-88 は C2/C3 シリアルインターフェースを使います。ゲームイメージ、ROM、フォント、SF2 は利用者が用意してください。

## ビルド

Windows でのビルドには **Python 3.11+、Node.js 22+、JDK 17+、CMake 3.22+** が必要です。プロジェクトのルートで、プレースホルダーを手元のパスに置き換えて実行します。

```powershell
node scripts/download.mjs
python -X utf8 scripts/extract.py
python -X utf8 scripts/build.py --jdk '<JDK_PATH>' --cmake '<CMAKE_EXE>'
```

スクリプトは Android SDK、NDK などの依存ファイルをプロジェクト内の `.cache/` と `work/` に配置し、両コアと画面をビルドして APK に署名します。出力先は `release/` です。

今後のビルドでも同じ署名で更新インストールできるよう、`.cache/signing/development.jks` を保管してください。

### ソースコードのパッケージ作成

```powershell
python -X utf8 scripts/package_sources.py
```

## コード構成

画面には Java 17 と Android 標準 UI を使い、エミュレーションホストには C/C++、JNI、ANativeWindow、AAudio を使っています。

| ディレクトリ | 内容 |
| --- | --- |
| `app/` | ゲームライブラリ、プレイ画面、入力、設定 |
| `native/` | エミュレーションスレッド、映像、音声、MIDI、コアの接続処理 |
| `third_party/` | M88、NP2kai、TinySoundFont のソース |
| `scripts/` | 依存ファイルの取得、ソースの適応、ビルド、パッケージ作成 |
| `tests/` | Java、ネイティブコード、Android の機能チェック |
| `release/` | APK とソースコードの ZIP |

## クレジットとライセンス

- PC-88 コアは cisc 氏の M88 をベースにしています。[M88](https://github.com/rururutan/m88)
- PC-98 コアは NP2kai をベースにしています。[NP2kai](https://github.com/libretro/NP2kai)
- MIDI 合成には MIT ライセンスの TinySoundFont v0.9 を使っています。[TinySoundFont](https://github.com/schellingb/TinySoundFont)

各コンポーネントの著作権表示とライセンス原文はアプリのリソースに収録し、**设置 → 来源与许可** からも確認できます。[ライセンス一覧](LICENSE.md) · [ライセンスファイル](app/src/main/assets/licenses/)
