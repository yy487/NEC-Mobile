# NEC Mobile

[简体中文](README.md) | [English](README.en.md) | **日本語**

PC-88 と PC-98 のゲームを Android で遊ぶためのエミュレーターです。M88 の PC-88 コアと NP2kai の PC-98 コアを一つのアプリに組み込み、ゲームライブラリ、リソース、マシン設定をプラットフォームごとに管理します。

現在のバージョンは **0.26.6**。**Android 8.0 以降の ARM64 端末**に対応しています。

- Android APK `NEC-Mobile-0.26.6-arm64.apk`
- ソースコード一式 `NEC-Mobile-0.26.6-sources.zip`

## 主な機能

- フォルダーや ZIP からゲームを取り込み、ディスク、カバー画像、最終プレイ日時をゲームカードで管理。
- プレイ中のフロッピーディスク交換と取り出し。PC-88 の D88 ファイルに格納された複数ディスクにも対応。
- 相対移動式のタッチパッドマウス、画面キーボード、物理キーボード入力、画面の自動回転。
- 機種、CPU、メモリー、サウンドボード、各音源の音量をゲームごとに保存。
- 各ゲームに 6 個の手動ステートセーブスロット。
- SF2 を使った MIDI 合成と、バックグラウンド移行や音声出力先の変更に伴う音声復帰処理。
- Compose / Material 3 のプラットフォーム選択、独立した設定画面、起動ディスク選択シート。
- 独立した自動セッション保存、実行速度、画面比率、端末の音声出力設定。
- PC-98 DOS フォルダーから専用 HDI の作成と FREECG98.BMP の選択。

## はじめに

以下のメニュー名は、アプリの中国語表記に合わせています。

1. APK をインストールしてアプリを開き、**PC-88** または **PC-98** を選びます。
2. 標準の起動用ファームウェアとフォントはアプリに同梱されています。ゲーム専用の ROM は **设置 → 导入系统 ROM / 字库** から取り込むか、ディスクと同じフォルダーや ZIP に入れて取り込めます。
3. **添加游戏** を押し、一つのゲームとそのディスク一式が入ったフォルダーまたは ZIP を選びます。
4. カードをタップして起動します。PC-98 は **游戏管理 → 启动环境与盘位**、PC-88 は **默认盘位** で設定できます。フロッピー A、B、ハードディスクを個別に装着し、起動デバイスを選択できます。

ゲームの進行状況は、取り込んだディスクのコピーに保存されます。次回カードをタップすると、記憶したディスク構成でマシンが起動します。

| プラットフォーム | 取り込めるディスク形式 |
| --- | --- |
| PC-88 | D88、88D。1 ファイルにつき最大 64 枚のディスクを格納可能 |
| PC-98 フロッピー | D88、88D、FDI、XDF、HDM |
| PC-98 ハードディスク | HDI、NHD、HDD、THD。起動ディスク設定から読み込み |

ゲームカードの **管理** から、名前の変更、マシン・音源設定、ディスクの書き出し、削除を行えます。カバー画像には、ファイル名が `cover`、`folder`、`front`、`title` の PNG、JPEG、WebP を使えます。プレイ中の画面を **菜单 → 更多设置 → 将当前画面设为封面** からカバーにすることもできます。

## 操作方法

半透明のフローティングボタンをタップするとショートカットを開閉できます。ドラッグして左右の端に移動でき、縦画面と横画面の位置を個別に保存します。Enter、キーボード、操作方式、メニューに加え、PC-88 では空白キーを使えます。戻るキーで展開中のパネルを閉じます。

**菜单 → 操作方式 / 鼠标** で自動設定、仮想マウス、スワイプキーを選びます。自動設定は適用済みプリセット、前回の操作方式の順に使用し、初回はスワイプキーになります。完全なマウス通信を検出すると **试用鼠标** を表示し、タップで選択をゲームごとに保存します。実行画面の操作方式ボタンはタップで切り替え、長押しで設定を開きます。切り替えは現在のタッチ操作が終わってから適用します。

**操作预设** ではテンキーまたは方向キーと Enter／空白、マウスタッチパッド、文字コマンド入力を選べます。対応するタイトルにはプリセット候補が表示され、適用すると現在のゲームに関連付けられます。

| 操作 | 動作 |
| --- | --- |
| 仮想マウスモードでスライド | ゲームのカーソルを相対移動 |
| 1 本指でタップ | カーソルの現在位置で左クリック |
| 2 本指でタップ | 右クリック |
| 約 350 ミリ秒長押ししてからスライド | 左ボタンを押したままドラッグ |
| 左下のマウスボタン | クリック、または押したまま別の指でスライド |
| 确认 / 空格 / 键盘 | Enter、Space の送信、または画面キーボードの表示 |

スワイプキーモードでは、上下左右の各ジェスチャーでテンキー 2/4/6/8 または方向キーを 1 回送信します。1 本指タップは選択した Enter または Space、2 本指タップはもう一方の確定キーです。数字の選択肢などには画面キーボードを使えます。画面の向きは **菜单 → 屏幕方向** で自動、横向き、縦向きから選べます。

バックグラウンドへの移行やオーディオフォーカスの喪失でゲームを一時停止します。前面に戻ってフォーカスを取得すると、手動の一時停止設定に従って再開します。イヤホンが切断された場合は、メニューから **继续运行** を選びます。音声出力を手動で再開するには、**菜单 → 更多设置 → 恢复声音输出** を使います。

## プレイ中のディスク交換

1. ゲームからディスク交換を求められたら、**菜单 → 更换 / 取出磁盘** を開きます。
2. ゲームが指定したフロッピードライブ A または B を選び、**换入其他盘** を押します。
3. 指定されたディスクを選び、ゲームに戻って指示に従います。

一覧には、そのゲームに取り込んだフロッピーが表示されます。複数枚を格納した D88 は、内部ディスク名や番号で選びます。空のドライブには **装入磁盘**、取り出しには **取出当前盘** を使います。ディスク交換は実行中のセッションに反映されます。ハードディスクイメージは起動設定から選びます。

## セーブと進行状況

**菜单 → 即时存档 / 读档** で 6 スロットのパネルを開き、保存、読み込み、削除を選びます。ゲームを起動し直した後も、保存済みのステートを読み込めます。

ステートには CPU、メモリー、デバイス状態、挿入ディスクの構成、MIDI チャンネルが保存されます。読み込み時には、復元したマシン状態とディスクの現在の内容を組み合わせて実行します。ゲーム内のセーブ機能は、進行状況をディスクのコピーに書き込みます。

ステート読み込み時は保存した装着構成を復元します。機種やハードディスク環境が異なる場合、保存時の設定でプレイ用プロセスを再起動します。過去のシステムディスクを保持し、ディスク削除時にステートからの参照を確認します。

ゲーム内セーブを保管するには、**管理 → 管理磁盘文件 → 导出磁盘副本** から該当ディスクを書き出します。ゲームの削除やアプリのアンインストールで、アプリ内のディスクとステートも削除されます。

**游戏管理 → 系统设置** で自動保存を有効にすると、バックグラウンド移行と通常終了時に専用スロットへ保存します。カードの **继续会话** から再開できます。手動の 6 スロットとは独立しています。復元できない場合は原因を表示し、通常起動も選べます。

## マシン・音源・MIDI 設定

ゲームカードの **游戏管理 → 系统设置** から設定を変更します。変更は次回起動時に反映されます。

- **PC-88** は N88-V1(S)、N88-V1(H)、N88-V2、N、N80、N80-V2 モード、4/8 MHz、拡張メモリー、OPN/OPNA、FM・SSG・ADPCM・リズム音量を設定できます。
- **PC-98** は VX/VM/PC-286、CPU/FPU プロファイル、メモリー、86・26K・118・SB16 などのサウンドボードとその組み合わせを選べます。音量調整は FM、SSG、ADPCM、PCM、リズム、BEEP に対応します。

PC-88 では主・副 CPU 比率、副 CPU のスケジューリング、CPU / FDD ウェイト、DIP-SW、PCG、表示タイミングも設定できます。PC-98 には音源 BIOS、GDC、走査線、パレット、LCD の設定を追加しました。

実行速度は 50%、100%、150%、200% で、音程も速度に従います。全速モードは消音です。画面は 4:3、元のピクセル比率、全画面、整数倍に対応し、原寸が収まらない画面では比率を保って縮小します。向きはゲームごとに保存します。

**设置 → 手机音频输出** で全ゲーム共通のサンプルレートとバッファーを変更できます。次回起動時に反映します。プレイ画面の **更多设置 → 实际音频输出** は現在の出力先と AAudio の実測値を表示します。コアの PCM は出力レートに合わせてリサンプリングします。

**游戏管理 → 字库设置 · FREECG98.BMP** から PC-98 フォントを選択・インポートできます。インポート後は選択を保存し、次回起動から使います。優先順位は手動選択、ゲーム同梱、共通インポート、標準フォントです。同じ出所では FREECG98.BMP、FONT.BMP、FONT.ROM の順です。2048×2048、1 ビット、非圧縮の BMP は実行用コピーを生成し、原本を保持します。前回起動の情報にコアが読み込んだ形式を表示します。

解凍時に Shift_JIS のディスク名を GBK として読み込んだ場合は、**游戏管理 → 修复磁盘名称编码** で復元結果を確認して適用できます。表示名だけを変更するため、ディスクの再インポートは不要です。

### MIDI

1. ホーム画面の **设置 → MIDI 音色库** から SF2 を取り込み、使用する音色ライブラリを選びます。1 ファイルの上限は 64 MB です。
2. そのゲームの **音源设置** で MIDI を有効にします。
3. ゲームを起動し、ゲーム側の設定でも MIDI 音楽を選びます。

TinySoundFont が選択した SF2 を使い、General MIDI の音楽を合成します。PC-98 は標準で MPU-98 の E0D0/E0D2 ポート、IRQ 6 を使います。PC-88 は C2/C3 シリアルインターフェースを使います。ゲームイメージと SF2 は利用者が用意してください。

## PC-98 DOS フォルダー

PC-98 ライブラリの **添加游戏 → DOS 游戏目录 / DOS 游戏 ZIP** から完全なフォルダーを取り込みます。標準テンプレートは FreeDOS(98) です。BAT / EXE / COM の起動ファイルを確認してディスクを作成できます。作業ディレクトリ、ドライブ文字、初期化コマンド、別のテンプレートは詳細起動設定から選べます。

ゲームごとに専用の書き込み可能な HDI を使います。名前はコードページ 932 の DOS 8.3 形式が必要です。不正な名前、重複、空き容量不足の場合は取り込みを中止します。独自テンプレートは PC-98 の FAT12 / FAT16 に対応し、IO.SYS、MSDOS.SYS、COMMAND.COM、または FreeDOS の KERNEL.SYS と COMMAND.COM を使用できます。ディスク管理から HDI を書き出してゲーム内セーブを保管できます。

ゲームごとに書き込み可能なシステムのコピーを作成します。特定の DOS が必要な場合は、用意した PC-98 用 HDI を取り込めます。

### 起動環境とセーブディスク

PC-98 の取り込み時にブート情報と DOS ファイルを確認します。DOS の欠落と起動ファイルを特定できる場合、専用システムディスクを作成します。独自の起動環境を持つゲームは付属ディスクを使用します。

**游戏管理 → 启动环境与盘位** で自動準備または FreeDOS(98) を選べます。起動候補が複数ある場合はデータディスクとディスク内のプログラムパスを指定し、**准备启动环境** を押します。ローカルビルドでは、用意した MS-DOS 2.1、3.3D、5.0A、6.2 のディスクや DOS 6.2 用 HIMEM / EMM386 を追加できます。

**管理磁盘文件 → 添加内置磁盘** から、書き込み可能な 1.2 MB FAT12 セーブディスクや DOS 保守ツールディスクを作成できます。プレイ中のディスク交換画面でもセーブディスクを作成し、A または B に装着できます。作成したディスクはゲームの一覧に保存され、再使用や書き出しが可能です。FreeDOS ツールディスクをフロッピー A から起動すると、DIR、COPY、TYPE、SYS などのコマンドを使用できます。

## 実行に必要なリソース

エミュレーターのコアと実行用ライブラリーは APK に含まれます。端末は Android 8.0 以降の ARM64 が必要です。

| リソース | 現在の提供方法 |
| --- | --- |
| ゲームディスク、完全な DOS フォルダー、専用ドライバー | 起動スクリプトや常駐プログラムも含めて利用者が用意 |
| PC-88 BASIC、フロッピー、文字・漢字 ROM | 対応する六つの BASIC モード用を同梱 |
| PC-98 互換 BIOS、標準フォント、標準音源 BIOS | 標準構成用をコアと APK で提供 |
| DOS システム | FreeDOS(98) を標準同梱し、別の PC-98 用 HDI テンプレートも取り込み可能 |
| SF2 音色ライブラリー | MIDI を使う場合に利用者が取り込み |
| 翻訳版や独自文字配置用のフォント | ゲーム付属のものを使用。標準フォントは同梱 |
| 別の音源 BIOS、PC-88 辞書・拡張 ROM | 対応ソフトや特殊な構成で必要な場合に用意 |
| OPNA リズムサンプル `2608_*.WAV` | 六つのサンプルを APK に同梱。取り込み後の小文字名と RYM / RIM の別名に対応 |

## ビルド

Windows でのビルドには **Python 3.11+、Node.js 22+、JDK 17+、CMake 3.22+** が必要です。プロジェクトのルートで、プレースホルダーを手元のパスに置き換えて実行します。

```powershell
node scripts/download.mjs
python -X utf8 scripts/extract.py
python -X utf8 scripts/build.py --jdk '<JDK_PATH>' --cmake '<CMAKE_EXE>'
```

Gradle Wrapper 9.1.0、AGP 9.0.0、Kotlin / Compose コンパイラー 2.2.10、API 36 Extension 19、NDK r28c を使います。SDK / NDK は `.cache/` に配置し、Gradle で Kotlin UI と 4 個のネイティブライブラリをビルドします。出力先は `release/`、バージョン定義は `version.properties` です。

更新には元の `.cache/signing/development.jks` を使います。新規プロジェクトでは同じパスに独自の RSA キーを作成し、alias を `necmobile`、開発用パスワードを `android` に設定できます。秘密鍵はソース ZIP に含めません。

標準ビルドは FreeDOS(98) を同梱します。用意した MS-DOS をローカルで組み込む場合は、指定先の `dos/` にファイルを配置し、`scripts/build.py --bundle-dos --dos-assets <リソースディレクトリ>` を実行します。 [リソースのファイル名](README.md)

### ソースコードのパッケージ作成

```powershell
python -X utf8 scripts/package_sources.py
```

## コード構成

ライブラリと設定画面は Kotlin と Compose / Material 3、業務処理とプレイ画面は Java 17 です。エミュレーションホストは C/C++、JNI、ANativeWindow、AAudio、DOS ディスク書き込みは FatFs を使います。

| ディレクトリ | 内容 |
| --- | --- |
| `app/` | ゲームライブラリ、プレイ画面、入力、設定 |
| `native/` | エミュレーションスレッド、映像、音声、MIDI、コアの接続処理 |
| `third_party/` | M88、NP2kai、TinySoundFont、FatFs のソース |
| `scripts/` | 依存ファイルの取得、ソースの適応、ビルド、パッケージ作成 |
| `tests/` | Java、ネイティブコード、Android の機能チェック |
| `release/` | APK とソースコードの ZIP |
